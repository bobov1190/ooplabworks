Formula 1

Develop a Java application, which allows Formula 1 organizers to manage standings of Formula 1 championship. All the classes must be in the package "formula1".


R1 - Drivers Definition

The system works through the facade class Championship. 

The method createDriver() accepts the driver name and creates a Driver object. The class Driver provides the method getName(), which returns the Driver’s name.

The method getDrivers() returns a Collections of Drivers. The method getDriver() receives the driver name as an input and returns the corresponding Driver object.


R2 - Grand Prix

The drivers compete in an undefined number of Grand Prix. The method defineGrandPrix() is used to define a GP. It receives the name of the GP (e.g. “Monza”) as a parameter. This method returns an object of type GP. The class GP offers the method getName(), which returns the GP name.

To obtain a specific GP it is possible to use the method getGrandPrix() of the class Championship, which receives the name of the GP as a parameter.



R3 - Time

The drivers who drive in a Grand Prix complete the race in a race time. This time can be stored into the system through the method setTime(), which receives as an input the corresponding GP object, the Driver object and the time expressed as hours, minutes, seconds, and cents.

This method returns an object of type Time, which overrides the method toString(), in order to print the race time in this format: "h:m:s.c" (e.g.. if h=1, m=30, s=5, c=40 the method returns "1:30:5.40").

Given a Grand Prix it is possible to get the race result by the method getGPRanking(), which returns a list of drivers sorted in ascending way based on the race time.



R4  - Ranking

Given a Grand Prix it is possible to get the ranking position of a driver by using the method getPosition(), which gets the corresponding driver object as an input. 

Given a driver it is possible to know which GP he raced by using the method getRaced().

Given a driver it is possible to know how many points he earned during the race based on this rule: 25 points for the first, 18 for the second, 15 for the third, 12 for the fourth, 10 for the fifth, 8 for the sixth, 6 for the seventh, 4 for the eighth, 2 for the ninth, 1 for the tenth. 

The method getPoints() returns and integer number which represents the number of points earned by the driver during the GP.

In the class Championship the method getChampionshipRanking() returns a collection of Drivers sorted in descending way based on the points earned by each driver during the championship.
